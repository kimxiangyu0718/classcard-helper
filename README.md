# ClassCard 단어 도우미 (크롬 확장)

classcard.net 단어장 자동 저장 + 테스트 정답 표시/자동 풀이 크롬 확장입니다.

## 사용 흐름

1. **단어장 페이지 열기** (`classcard.net/set/...`) → 페이지의 단어+한국어 뜻이 **자동 저장**됩니다 (오디오 URL도 함께 저장)
2. **테스트 버튼 클릭** → 영→한 / 한→영 문제가 나오면:
   - 오른쪽 아래 패널에 **문제와 정답이 즉시 표시**됩니다
   - 화면의 정답 보기에 **초록 테두리 + "정답" 라벨**이 붙습니다
3. **자동 풀이 ON** → 정답 클릭 → 다음 버튼 클릭 → 시작 화면(설정→테스트 시작)까지 자동 진행
4. **다른 세트 페이지로 이동** → 그 페이지 단어를 **자동으로 다시 저장** (이전 세트 데이터는 유지, 테스트 단어는 "현재 저장된 페이지" 기준으로 매칭)

## 설치 (개발자 모드 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램 로드** 클릭 → 이 `classcard-helper` 폴더 선택
4. classcard.net 접속 → 우측 하단에 "단어 도우미" 패널이 나타나면 성공

## 패널 조작

| 요소 | 기능 |
|---|---|
| 문제/정답 칸 | 현재 문제 → 저장된 사전에서 찾은 정답 (+몇 번 보기인지) |
| 정답 강조 체크 | 화면의 정답 보기에 초록 테두리 표시 (기본 ON) |
| 자동 풀이 체크 | 정답 클릭 + 다음 진행 자동화 (기본 OFF) |
| 오답 조절 체크 | 자동 풀이 중 무작위로 일부러 틀려 점수를 목표에 맞춤 (기본 ON) |
| 목표 점수 | 80~100 사이 설정 (기본 85). 합격선 80 미만으로 떨어지는 일이 없도록 계산 |
| 클릭 지연 | 자동 클릭 사이 무작위 대기 시간 ms (자연스러운 페이스) |
| 단어 다시 저장 | 현재 페이지 단어를 다시 읽음 |
| 헤더 드래그 | 패널 위치 이동 (기억됨), `—` 버튼으로 최소화 |

단축키: `Alt+Shift+H` 정답 강조 토글 / `Alt+Shift+A` 자동 풀이 토글 (크롬이 다른 단축키를 요구하면 `chrome://extensions/shortcuts`에서 지정)

팝업(툴바 아이콘 클릭): 총 저장 단어 수, 세트 목록/삭제, JSON 내보내기, 전체 삭제, 설정

## 지원 모드

- **테스트** (영→한, 한→영 객관식): 문제 식별 → 사전 매칭 → 정답 표시/강조/자동 클릭
- **리콜학습** (4지선다): 정답이 DOM에 있어 바로 강조/자동 클릭
- **스펠학습**: 정답 단어 표시, 자동 모드에선 입력란에 입력+엔터
- **암기학습**: 뜻 표시, 자동 모드에선 커버 열기→다음 카드

## 매칭 규칙 (정답을 찾는 방법)

- 문제와 보기의 공백/구두점/대소문자/품사태그(`[명]`)를 정리해서 비교
- 완전 일치 > 부분 포함("흔적, 자취"에서 "자취"만 보기로 나와도 인식)
- 듣기 문제는 단어 오디오 파일명으로 역조회 (저장 시 mp3 URL을 함께 저장하기 때문)
- 사전에 없는 단어가 나오면 패널에 "저장되지 않은 단어" 안내 → 그 문제만 직접 풀면 됨

## 오답 조절 (점수 컨트롤) 동작 방식

- 목표 85점이면 허용 오답 예산 15%를 두고, 문제마다 확률적으로 무작위 보기를 틀리게 클릭
- **보장 규칙**: "지금까지 푼 문제 중 오답 비율"이 항상 (100−목표)% 이하로 유지되므로,
  시험이 중간 어느 시점에 끝나도 최종 점수가 목표(≥80) 미만이 되지 않음
  (20문항·목표85 시뮬레이션 2만 회 결과: 최저 순간 점수 85.0, 최종 평균 87.6점)
- 오답은 연속으로 나오지 않도록 분산되고, 목표보다 오답이 부족하면 확률이 살짝 올라가 균형을 맞춤
- 듣기 문제처럼 정답을 모르는 문제는 오답 1개로 보수적으로 계산
- 패널에 `오답 2/13 · 예상 ~85점` 식으로 실시간 표시, 세션 종료 시 최종 예상 점수 안내
- 스펠 모드는 정답의 마지막 글자를 빼고 입력해 틀리게 처리, 리콜/테스트는 오답 보기 중 무작위 선택

## 주의

- 테스트 문제는 "지금 저장한 페이지 단어"로만 맞춰집니다. 선생님이 다른 세트를 섞어 출제하면 그 단어는 매칭이 안 됩니다.
- 사이트 개편으로 클래스명이 바뀌면 강조/자동화가 안 될 수 있습니다. 그때는 힌트(패널 정답 표시)만으로도 사용 가능합니다.
- 자동 풀이는 일반 클릭 이벤트를 보내는 방식이라, 사이트가 비정상 입력을 감지하면 동작하지 않을 수 있습니다. 감지 리스크를 줄이려면 클릭 지연을 늘리거나 정답 강조(수동 클릭)만 사용하세요. 학습 기록은 사이트 서버에 그대로 남습니다.

## 파일 구조

```
classcard-helper/
├── manifest.json    확장 설정 (MV3)
├── content.js       단어 저장 + 문제 감시/정답 처리 + 패널
├── content.css      패널/강조 스타일
├── background.js    배지, 단축키
├── popup.html/js    팝업 (세트 관리/설정/내보내기)
└── icons/icon128.png
```

## 문제 해결

- **패널이 안 보임**: `chrome://extensions`에서 확장 활성화 확인 → classcard.net 새로고침
- **단어 저장이 0개**: 세트 페이지에서 "더보기/전체"를 누른 뒤 패널의 "단어 다시 저장"
- **정답 강조가 안 붙음**: 사이트 HTML 구조 변경 가능성 → content.js의 `quizChoices()` 셀렉터 조정 필요
